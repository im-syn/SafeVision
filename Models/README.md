> [!IMPORTANT]
> **Do not tell a customer that every SafeVision model is Apache-2.0.** The
> model files have different origins and licenses. Two YOLO exports explicitly
> contain Ultralytics AGPL-3.0 metadata, one old model has no established
> license, and the new age/gender model is published as Apache-2.0 by its
> Hugging Face repository.

## 📦 Required and optional files

| Check selection | Required files | Behavior when absent |
|---|---|---|
| `nude` / `nsfw` | `best.onnx` | NSFW-enabled run fails or attempts the supported download path |
| `age` | Age/gender ONNX file | Clear missing-model error |
| `gender` | Age/gender ONNX file | Clear missing-model error |
| `objects` | `safety_objects.onnx` + `safety_objects.labels.json` | Object-enabled run fails clearly |
| `nude,age,gender` | `best.onnx` + age/gender ONNX | Default three-check workflow |
| `all` | Every active model and labels file | NSFW, demographics, and safety objects |
| `none` | No model | Rendering-only operations such as forced full cover |

## ⬇️ Install the age/gender model

The large age/gender file is intentionally ignored by Git. Download the exact
published ONNX file from the repository root:

```powershell
Invoke-WebRequest `
  -Uri "https://huggingface.co/onnx-community/age-gender-prediction-ONNX/resolve/main/onnx/model.onnx" `
  -OutFile ".\Models\onnx-communityage-gender-prediction-ONNX.onnx"
```

Verify it:

```powershell
Get-FileHash `
  ".\Models\onnx-communityage-gender-prediction-ONNX.onnx" `
  -Algorithm SHA256
```

Expected SHA-256 for the currently documented file:

```text
0c35c868ea8ffba6d5fe727c1a6b82d9da600e690342d58ca268270560e28304
```

If upstream publishes a new revision, verify its model card, license, behavior,
and checksum before replacing this documented value.

## 🧠 Runtime notes

- The age/gender model uses ONNX opset 18 and requires ONNX Runtime 1.18 or
  newer in this project.
- SafeVision creates sessions lazily and reuses them.
- Multiple faces in one frame are batched.
- NSFW face detections are reused for demographics where possible.
- `CPUExecutionProvider` is the portable default; accelerators need their own
  runtime and drivers.
- Model outputs are estimates and must not be treated as legal-age proof,
  identity, or a legal conclusion.

```powershell
python safeVisionCLI.py status
python safeVisionCLI.py providers
python main.py --help
```

## 🚢 Release checklist for model files

Before publishing or attaching any model to a GitHub Release:

1. record its exact origin URL, author, version, and acquisition date;
2. preserve the original license and notice files;
3. inspect ONNX metadata and compute SHA-256;
4. record the base weights/framework and all dataset licenses;
5. confirm redistribution and commercial-production rights;
6. do not label an unknown model as SafeVision-owned;
7. update this registry and `docs/LICENSING.md`;
8. validate accuracy, bias, privacy, and safety limitations independently.
